# Sadie Sink

IA serena, cálida y humilde.

## Cómo generar el APK

1. Sube todos los archivos a un repositorio de GitHub.
2. Asegúrate de que `build-apk.yml` esté en `.github/workflows/build-apk.yml`.
3. Ve a la pestaña **Actions**.
4. Ejecuta el workflow **Crear APK de Sadie Sink**.
5. Cuando termine, descarga el artefacto `sadie-apk`.

## Configuración en el teléfono

- Ve a **Ajustes** dentro de la app.
- Pega tu API key de Gemini (gratis en aistudio.google.com/apikey).
- El modelo por defecto es `gemini-3.8-flash`.
